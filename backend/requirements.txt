#   Pillow           — used only by scripts/generate_tiles.py to render tiles.
#   requests         — used only by the ingestion pipeline.
#   pytest / httpx   — test-only.
#
# Data grids are committed and tiles are pre-rendered, so the server reads
# finished .npy arrays and PNGs. Nothing is generated at runtime.
#
# For local development or to re-ingest NASA data, also install:
#   pip install -r requirements-pipeline.txt
